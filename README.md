# 🏖️ Sistema de Gestão de Férias

Sistema web desenvolvido para auxiliar a equipe de Recursos Humanos (RH) no gerenciamento e acompanhamento de férias dos colaboradores.

O projeto busca centralizar informações, facilitar a organização dos períodos de férias e tornar o processo de gestão mais prático e eficiente.

## 🌐 Acesso ao projeto

- **Sistema online:** https://sistema-de-ferias-a2ou-jzqc8r0ct-senai-1da5.vercel.app
- **Repositório GitHub:** https://github.com/nicolasmigueltavares2007-maker/sistema-de-ferias-

## 🎯 Objetivo do projeto

Desenvolver uma aplicação web voltada à equipe de Recursos Humanos, oferecendo uma solução digital para apoiar a administração de férias dos colaboradores.

A proposta é reduzir processos manuais, organizar informações e facilitar o acompanhamento das solicitações e dos períodos de descanso.

## 🛠️ Tecnologias utilizadas

O projeto utiliza as seguintes tecnologias:

| Tecnologia | Finalidade |
|---|---|
| React | Construção da interface |
| TypeScript | Tipagem e organização do código |
| Vite | Ambiente de desenvolvimento |
| Tailwind CSS | Estilização da aplicação |
| Supabase | Serviços de banco de dados |
| Google Gemini API | Integração com inteligência artificial |
| Express | Estrutura de servidor |
| Lucide React | Ícones da interface |

## 💻 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/nicolasmigueltavares2007-maker/sistema-de-ferias-.git
```

### 2. Entre na pasta

```bash
cd sistema-de-ferias-
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Configure as variáveis de ambiente

Consulte o arquivo `.env.example` e configure as variáveis necessárias para as integrações utilizadas pelo projeto.

### 5. Execute a aplicação

```bash
npm run dev
```

### 6. Acesse no navegador

```text
http://localhost:3000
```

## 🚀 Build de produção

Para gerar a versão de produção:

```bash
npm run build
```

Para visualizar a versão gerada:

```bash
npm run preview
```
